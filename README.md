### 🎟️ [Rolê 60+ | AppSec & Inscrições](https://role60mais.com.br)

* **Tech:** PHP RESTful, JavaScript, MySQL, Mercado Pago API.
* **Destaques:** Proteção contra manipulação de preços de lotes, Rate Limiting, Prevenção IDOR (HMAC-SHA256) e checkout PIX transparente.
* 🌐 **[Acessar a Plataforma Ao Vivo](https://role60mais.com.br)**

### 📊 [RaloZero: Financial Intelligence Dashboard](https://github.com/taisohenrique/RaloZero)
Dashboard de BI de alto impacto que transforma planilhas financeiras em decisões estratégicas.
* **Tech:** Python 3.11, Streamlit, Pandas, Plotly.
* **Destaques:** Métricas de faturamento/lucro em tempo real e análise de "ralos" financeiros.
* 🌐 **[Acessar Aplicação Web](https://ralozero-uj6qeaumdfzgadt9v7dqsu.streamlit.app/)**

* **Tech:** Python, APIs Financeiras, Gestão de Dados.

Desenvolvimento de soluções de infraestrutura interna para o Conselho Regional de Administração.
